# Claude Code 主窗口右键菜单参考（实机截图梳理）

> 用途：dsh-agent-menu 重设计 + 发布前的对照基准。
> 设计方向：仿 Claude 风格的右键菜单为主轴。
> 来源：主人 2026-10-28 提供的 Claude Code 实机截图（主窗口对话框区域）。
> 状态：第一批（对话框区域）。其他位置的右键交互主人后续补发。

## 总体风格观察

- 菜单为浅色卡片、圆角、细阴影，项与项之间有细分隔线分组。
- 文字项为主，危险/次级操作用灰色小字在下方做一行说明（如「从此处分叉」下的「开始新会话，保留当前会话」）。
- 快捷键右对齐、灰色（如 `Ctrl+C`、`Ctrl+Shift+L`）。
- 子菜单用行尾 `›` 箭头，悬停展开（如「复制」「打开方式」）。
- 不同右键目标弹出**不同组合**的菜单：纯文本 / 选中文字 / 代码块 / 图片 / 链接 / 文件路径，各自有自己的一套项。

## 按右键目标分类

- 复制消息

- 标记为章节
- ─────
- 从此处分叉
  - 开始新会话，保留当前会话（灰色说明文字）

### 2. 有选中文字时
- 复制  `Ctrl+C`
- 复制消息
- 将消息复制为 Markdown
- 将所选内容作为上下文附加  `Ctrl+Shift+L`
- 标记为章节
- ─────
- 从此处分叉
  - 开始新会话，保留当前会话

差异点：多了「复制 Ctrl+C」和「将所选内容作为上下文附加 Ctrl+Shift+L」（替代了「将消息附加为上下文」）。

### 3. 代码块上
- 复制代码
- 复制消息

- 将消息附加为上下文
- 标记为章节
- ─────
- 从此处分叉
  - 开始新会话，保留当前会话

差异点：顶部多「复制代码」。

### 4. 图片上
- 复制图片
- 保存图片
- ─────
- 标记为章节
- ─────
- 从此处分叉
  - 开始新会话，保留当前会话

差异点：顶部是图片专属操作，没有「复制消息/复制为 Markdown/附加为上下文」。

另有一张更精简的图片菜单（可能来自不同上下文，如缩略图/嵌入图）：
- 复制图片
- 保存图片

### 5. 文件路径上
- 作为上下文附加
- 复制 ›
  - 绝对路径
  - 文件名
  - 相对路径（另一张截图里出现，说明子项可能随场景补全）
- 打开方式 ›
  - VS Code（检测到的可用编辑器）
  - 文件面板

差异点：这是文件路径专属菜单，没有「复制消息」「标记为章节」「从此处分叉」。

### 6. 链接上
- 在 Microsoft Edge 中打开
- 在浏览器窗格中打开
- 复制链接
- ─────
- 复制消息
- 将消息复制为 Markdown
- 将消息附加为上下文
- ─────
- 回退到此处
  - 删除此消息及其后续内容（灰色说明）
- 从此处分叉
  - 开始新会话，保留当前会话

差异点：顶部链接专属三项；中部额外出现「回退到此处」（删除此消息及其后续内容）——这是普通消息菜单里没有的危险操作。

## 摘录（Quote）交互

选中文字后，除了右键菜单，Claude 还会：
- 在选区附近弹一个小浮条：「回复 Claude」（带一个引用/箭头图标）。
- 触发后，在输入框上方生成一个**摘录卡片**：显示选中的文字片段，左下角有「摘录」标签。
- 摘录卡片右上角有 `×` 可移除。

这与右键菜单里的「将所选内容作为上下文附加 Ctrl+Shift+L」是同一族交互：一个走浮条/快捷键，一个走右键。

## 菜单项全量清单（去重）

消息级：
1. 复制消息
2. 将消息复制为 Markdown
3. 将消息附加为上下文
4. 将所选内容作为上下文附加 `Ctrl+Shift+L`
5. 标记为章节
6. 回退到此处（删除此消息及其后续内容）
7. 从此处分叉（开始新会话，保留当前会话）

目标专属：
8. 复制 `Ctrl+C`（选中文字）
9. 复制代码（代码块）
10. 复制图片 / 保存图片（图片）
11. 作为上下文附加（文件路径）
12. 复制 › 绝对路径 / 相对路径 / 文件名（文件路径）
13. 打开方式 › VS Code / 文件面板 / 默认应用（文件路径）
14. 在资源管理器中显示（文件路径）
15. 在 Microsoft Edge 中打开 / 在浏览器窗格中打开 / 复制链接（链接）

## 对 dsh-agent-menu 重设计的启示

- 菜单项应按右键目标类型动态组合，而不是一份固定菜单。
- 危险操作（回退/删除）要有灰色说明文字，与「从此处分叉」这类安全操作在视觉上同族但语义不同。
- 快捷键标注（Ctrl+C / Ctrl+Shift+L）是 Claude 风格的标志性细节。
- 「标记为章节」是 Claude 的组织维度功能，DSH 侧可考虑对应「章节/书签」能力。
- 「从此处分叉」对应 DSH 的 session fork；「回退到此处」对应 rewind/delete-after。
- 摘录卡片 + 「回复 Claude」浮条是独立于右键菜单的选区交互，可作为二期目标。

## 输入框（Composer）区域右键菜单（第二批，2026-10-28）

输入框的菜单与对话区风格不同：更接近系统原生编辑菜单，快捷键标注更全（Ctrl+Z/Y/X/C/V/A），且会随右键目标（链接 / 图片 / 附件）叠加专属项。

### 7. 输入框 · 链接上
- 在默认浏览器中打开链接
- 复制链接地址
- ─────
- 撤销  `Ctrl+Z`
- 重做  `Ctrl+Y`
- ─────
- 剪切  `Ctrl+X`
- 复制  `Ctrl+C`
- 粘贴  `Ctrl+V`
- ─────
- 全选  `Ctrl+A`

要点：链接专属项置顶，下面是完整的原生编辑菜单（含撤销/重做/剪切，这些在对话区菜单里没有）。

### 8. 输入框 · 图片上
- 复制图片
- 复制图片地址
- ─────
- 复制  `Ctrl+C`
- ─────
- 全选  `Ctrl+A`

要点：图片专属项是「复制图片 / 复制图片地址」（对话区图片是「复制图片 / 保存图片」，不同）；下面只有复制/全选，没有剪切/粘贴/撤销/重做（图片上这些操作无意义）。

### 9. 输入框 · 附件（文件 chip）上
- 复制 ›
  - 绝对路径
  - 文件名
- 在资源管理器中显示

要点：附件菜单极简，只有路径复制子菜单和资源管理器显示。与对话区文件路径菜单相比，没有「作为上下文附加」（因为附件本身已经在上下文里），也没有「打开方式」子菜单，也没有「相对路径」子项。

### 输入框 vs 对话区 · 差异总结

| 维度 | 对话区 | 输入框 |
|---|---|---|
| 编辑操作（撤销/重做/剪切/粘贴/全选） | 无 | 有，带完整快捷键 |
| 链接项 | 在 Edge / 浏览器窗格中打开 | 在默认浏览器中打开 |
| 图片项 | 复制图片 / 保存图片 | 复制图片 / 复制图片地址 |
| 文件/附件项 | 作为上下文附加 + 打开方式 + 相对路径 | 仅复制路径 + 资源管理器显示 |
| 消息级操作（复制消息/章节/分叉/回退） | 有 | 无 |

## 左侧栏（会话列表）区域右键菜单（第三批，2026-10-28）

侧栏菜单引入了两个新的视觉特征：
- **单字母快捷键**（P / U / R / F / A / D），右对齐灰色，与对话区的 Ctrl 组合键不同。
- **危险项用红色文字**（删除所有会话 / 删除），不再只是灰色说明文字。
- **批量操作带计数**（全部归档（26）/ 删除所有会话（26））。

### 10. 侧栏 · 空白区域 / 列表容器
- 新建会话
- ─────
- 另存为环境
- 上移
- ─────
- 全选
- ─────
- 全部折叠
- 全部展开
- ─────
- 全部归档（26）
- 删除所有会话（26）  ← 红色

要点：这是列表级批量操作菜单。「另存为环境」是会话列表导出/快照功能；「上移」可能是排序；「全选/全部折叠/全部展开」是列表视图控制；底部两个批量危险操作带会话计数。

### 11. 侧栏 · 单个会话项
- 打开方式 ›
- ─────
- 置顶  `P`
- 标记为未读  `U`
- 重命名  `R`
- 分叉  `F`
- ─────
- 移至分区 ›
- 在项目中继续 ›
- ─────
- 归档  `A`
- 删除  `D`  ← 红色

要点：单会话操作全集。每个操作都有单字母快捷键。「打开方式」「移至分区」「在项目中继续」都有子菜单。

### 12. 侧栏 · 会话项 · 打开方式子菜单
- 分屏视图  `1`
- 新建窗口  `2`
- ─────
- 打开方式（灰色分组标题）
- VS Code  `3`
- 文件资源管理器  `4`
- ─────
- 在以下位置继续（灰色分组标题）
- 云端  `5`
  - 无需您的电脑即可运行（灰色说明）

要点：子菜单用数字键 1-5 作为快捷键。中间用灰色小字做分组标题（「打开方式」「在以下位置继续」），不是分隔线而是文字标签。「云端」带说明文字「无需您的电脑即可运行」。

### 侧栏 · 风格新发现

| 特征 | 对话区/输入框 | 侧栏 |
|---|---|---|
| 快捷键 | Ctrl 组合键 | 单字母（P/U/R/F/A/D）+ 数字（子菜单 1-5） |
| 危险项 | 灰色说明文字 | **红色文字** |
| 批量计数 | 无 | 有（26） |
| 子菜单分组 | 无 | 灰色文字分组标题 |
| 子菜单说明 | 无 | 有（云端 → 无需您的电脑即可运行） |
