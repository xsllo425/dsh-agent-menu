# v0.8.2 — 侧栏菜单：重排、汉化、删除会话

## 改了什么

- **工作区右键菜单重排**：「新建会话」插到最上面，「复制工作目录」「打开文件位置」插在「删除工作区」之前——「删除工作区」沉底。此前追加项一律排在尾部，删除项反而在第二位，容易误点。
- **会话右键菜单汉化**：宿主内置的「复制 Session ID」在菜单打开后就地替换为「复制会话 ID」（只认精确文案，宿主改版时自然失效，不会误改别项）。
- **会话菜单新增「删除会话」**：排在「复制会话 ID」之后；官方插槽与右键 DOM 兜底双路径（部分环境插槽不渲染插件项），只出现一次。DSH 没有公开的会话删除接口，本插件宿主路由 `POST /agent-menu/session-delete` 复刻了已验证的做法：删除 `~/.dsh/sessions/<工作区>/<会话id>` 日志目录并清除归档标记，成功后刷新侧栏。

## 删除会话的行为边界

- 正在本应用打开的会话会被拒绝（409），提示重启后再删除。
- 目录本就不存在（ghost 会话）按删除成功处理，只清归档标记。
- 解析出的会话目录必须位于 `~/.dsh/sessions` 之内（realpath 守卫），越界返回 403。
- 无确认对话框，与归档视图垃圾桶的既有习惯一致；点下即删，日志目录不可恢复。

## 安装

```bash
dsh plugin --profile desktop add github:xsllo425/dsh-agent-menu#v0.8.2
```

## 验证

- `npm run verify`：语法检查、40 项测试、清单自检全部通过。
- 界面行为（重排顺序、汉化替换、删除后侧栏刷新）需在 DSH 重启后人工确认。
