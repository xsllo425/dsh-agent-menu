# v0.8.3 — 修复旧格式会话目录删不掉

## 改了什么

- **删除会话现在能找到旧格式目录**：宿主的会话日志目录有过两种命名——裸 `<会话id>` 与旧的 `session-<会话id>`。0.8.2 只找前者，旧会话被当成"目录本来就不存在"（ghost）报删除成功，实际什么都没删。现在两种命名都会查找并删除。
- **占用判定行为不变**：本次应用运行里打开过的会话会被判为占用（409，提示重启后再删），与归档视图垃圾桶的既有习惯一致——宿主在运行期内保留常驻实例，插件无法区分"开着"和"开过"。

## 安装

```bash
dsh plugin --profile desktop add github:xsllo425/dsh-agent-menu#v0.8.3
```

## 验证

- `npm run verify`：语法检查、42 项测试、清单自检全部通过。
- 本机实测：旧格式目录会话在 0.8.2 上返回 `ghost:true` 但目录仍在（bug 复现）；修复后需重启宿主验证真实删除。
