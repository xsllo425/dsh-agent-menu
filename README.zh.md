# dsh-agent-menu

> **0.5.0 本地精简（2026-10-19）**：只在对话消息（`[data-chat-turn]`）和输入框里接管右键，其他地方放行；消息里只认图片、点在选区上的选中文字、链接、文件路径。去掉了引用到输入框、发送给 AI、解释/翻译/总结/续写/代码模板、复制此段、代码块专属菜单。等待短语的页面监听改成每帧最多处理一次。测试：`node tests/scope.mjs`（smoke.mjs 测的是 0.4.x 行为，已过期）。备份：`E:\Backups\agent-menu-20261019`。


为 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)（DSH）补上一个 **Agent 级右键菜单**——交互设计参考 Codex、WorkBuddy、MiniMax 等主流 Agent。

右键选中文字、超链接、文件芯片、一段代码或一张图片，就能**引用进输入框**、**直接发给 AI**，或者套用提示模板（解释 / 翻译 / 总结 / 续写 / 代码优化与测试）；同时把剪贴板、复制图像、另存为、打开文件位置、用默认应用打开这些**原生能力**也一并接管，不依赖任何别的右键菜单插件。

## 功能

菜单**按点击的目标分**：每种目标有自己的菜单项集；目标不在白名单内时**完全不接管**，浏览器原生菜单照常弹出。0.2.0 起菜单**完全自足**，不再需要 dsh-file-menu。

| 右键位置 | 菜单项 |
|---|---|
| 选中的文字 | **引用到输入框** · **发送给 AI** · 让 AI 解释 · 翻译选区（自动判断中英方向）· 总结选区 · 续写 ·（在代码里时）优化这段代码 · 生成单元测试 · 复制 |
| 选区正好是文件路径 | 上面全部 + **复制路径** · **打开文件位置** · **用默认应用打开** |
| 选区在超链接里 | 上面全部 + **复制链接地址** · **在浏览器中打开** · **复制为 Markdown 链接** |
| 超链接（无选中） | **复制链接地址** · **在浏览器中打开** · **复制为 Markdown 链接** ·（这段文字值得问 AI 时）引用此段到输入框 · 让 AI 解释此段 |
| 文件芯片 / 工具行文件链接 | **复制路径** · **打开文件位置** · **用默认应用打开** · 复制相对路径 · 复制本地文件链接 · 复制文件名 |
| 代码块（无选中） | 复制代码 · **复制为代码块**（带 ```lang 围栏）·（有语言标记时）复制（不带语言标记）· 引用代码到输入框 · 让 AI 解释这段代码 · 优化这段代码 · 生成单元测试 |
| 对话区里的图片 | **在新标签页中打开图像** · **复制图像** · 复制图片地址 ·（本地图时）打开文件位置 · 用默认应用打开 · **另存为…** |
| 输入框（无选区） | 粘贴 · 撤销 · 重做 · 全选 |
| 输入框（有选区） | 剪切 · 复制 · 粘贴 · 撤销 · 重做 · 全选（**刻意不给 AI 项**——还没发出去，作用意义不大） |
| 输入框里的图片 | 复制图像 · 复制图片地址 ·（本地图时）打开文件位置 / 用默认应用打开 / 另存为 · **从输入框移除** |
| 段落（无选中） | 引用此段到输入框 · 让 AI 解释此段 · 总结此段 |
| 左侧工作区 / 会话树 | **触发 DSH 原生菜单**（和点行内 ⋮ 按钮完全一样：置顶 / 重命名 / 分叉 / 归档 / 删除，含快捷键与红色危险色） |
| 其它（空白区、工具栏、状态栏……） | **不接管** |

- **引用到输入框**：把内容追加到输入框现有草稿之后（不覆盖你已输入的话），并聚焦输入框，方便补一句再发。
- **发送给 AI**：以你的身份直接发出这条消息——和 dsh-suggest-actions 走同一条官方通道
  （`conversation.input.shell(sessionId).actions` 的 `setDraft` + `submit`），不是模拟按键。
- **翻译**：自动判断选区以中文为主就翻成英文，否则翻成中文。
- **提示模板**：解释 / 翻译 / 总结 / 续写 / 代码操作都是「模板 + 选中内容」组装成消息发出，
  超过 2 万字符的内容会截断并标注，避免一条消息塞进整篇文档。
- **路径识别**：DSH 对工作区内的文件只显示相对路径，工具行的文件按钮更是既没有 `title`
  也没有 `data-path`——路径只写在文本里。所以本插件会依次看 6 个属性
  （`data-path` / `data-file-path` / `data-filepath` / `data-file` / `title` / `aria-label`）、
  `dataset` 里键名含 `path` 的属性、以及代码 / 路径文本，再拼上当前会话的工作区根还原成绝对路径。
- **图片识别**：DSH 的所有会话媒体都挂在同一条认证路由上——`GET /api/file?path=<绝对路径>`，
  所以图片的本地路径**直接从 `<img>` 的 src 里解出来**，不用猜。解不出来（远端图、`data:` URL）
  就**隐藏**「打开文件位置 / 另存为」这两项，只留不依赖本地路径的项——宁可少一项，绝不误报。
- **原生能力**走宿主路由（`lib/index.js`）：系统剪贴板优先用 Electron 主进程、退回 PowerShell
  `Set-Clipboard`；「复制图像」用 Electron `nativeImage` 写系统剪贴板（渲染层做不到——`/api/file`
  是认证路由，fetch 拿不到 blob，而 `ClipboardItem` 要求同源）；「另存为」走 Electron 存档对话框
  且**复制而非移动**（原档必须留在会话里）；「打开文件位置」在 Windows 上用 `explorer.exe /select,`
  且必须开 `windowsVerbatimArguments`（不开会被 Explorer 忽略开关、落到错误目录，见开发文档的踩坑记录）。
  宿主路由不可用时，复制会退回浏览器本地复制，其余操作给出明确提示。
- 没有活动会话（取不到输入框 shell）时，菜单里不会出必然失败的 Agent 项，只保留复制 / 文件 / 链接这类纯本地操作。

## 安装

```sh
dsh plugin --profile desktop add <本目录或 tarball 路径>
```

profile 名写你实际在用的（本机桌面版是 `desktop`，Web 客户端是 `web`）。装完**重启 DSH** 才会加载。

手工装（不经过插件管理器）也可以：把本目录放进任意位置，然后在 profile 的 `package.json`
里加两条——依赖写成 `"dsh-agent-menu": "file:<绝对路径>"`，
`dsh.profile.bundles` 数组里加一行 `"dsh-agent-menu"`。之后重启 DSH。

## 与其他右键菜单插件共存

多个右键菜单插件可以同时安装，本插件按下面的规则让位：

- **dsh-file-menu**：它先处理右键。它弹了菜单时——若本次右键本插件**也有**菜单项，本插件**接管**
  它的菜单（0.3.0 的菜单是本插件的超集，不丢功能）；本插件没项时让它的菜单留着。
  它没弹，本插件就自己弹。
- **dsh-round-rightclick**（圆盘菜单）：它的全屏遮罩出现时本插件一律让行。

不装这两个插件，本插件也完全独立可用——事实上 0.2.0 的目标就是**替代**它们。

## 原理

- **客户端半幀** `lib/client.js`：捕获阶段监听 `contextmenu` + 纯 DOM 菜单（不依赖 React）；
  菜单项激活走 window 捕获阶段的 `pointerdown` + `elementFromPoint` 命中，避免上游 `stopPropagation`
  把点击吞掉。事件回调里不同步决策，而是记下上下文后 `setTimeout(0)` 再决定——此时别的插件的
  同步处理已经结束，决策与模块加载顺序无关。
- **分类与放行**：`classify(context)` 先算出这是哪一类目标（可编辑区 / 选区 / 图片 / 代码块 /
  超链接 / 文件芯片 / 段落），**返回 `null` 就不 `preventDefault`**，让浏览器原生菜单照常弹出。
  这是防误触的关键：点空白、点工具栏、点状态栏都不会被吞。
- **侧边栏是特例**：在 `classify` **之前**先看 `sidebarRowOf(target)`——命中官方侧边栏的行
  （`data-row-key` / `role="treeitem"`）就直接 `click()` 那一行的 ⋮ 按钮，把 DSH 原生菜单请出来，
  自己不出菜单。所以菜单内容、快捷键、危险色与官方一模一样，且不用维护一份复刻。
- **会话与输入框**：客户端 `sessions` 服务取当前会话 id 与工作区根，`conversation` 服务取输入框 shell；
  `setDraft` 是 Lexical 异步更新，提交前轮询等草稿落定（同一 tick 连调会发空草稿）。
- **宿主半幀** `lib/index.js`：在 `webServer` 上注册一个 `/agent-menu` 前缀路由，提供
  `ping` / `status` / `hello` / `menu` / `clipboard` / `copy-image` / `save-image` / `reveal` / `open`；
  客户端 bundle 由 DSH 的 `dsh.client` 声明自动下发。
  `GET /agent-menu/status` 会返回运行时统计（客户端版本、弹菜单次数、复制 / 复制图像 / 另存为 /
  定位 / 打开次数、最近 40 条行为记录），没有浏览器控制台时也能确认插件到底跑没跑。

维护者笔记（共存细节、踩坑记录）见 [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)。

## 限制

- **左侧工作区 / 会话树：不自己出菜单，改为触发 DSH 原生那一个**（和点行内 ⋮ 按钮完全一致）。
  官方菜单在 `@deepseek-ai/dsh-client-ui-workspace` 里由 React state 控制，我们只是找到那一行的
  ⋮ 按钮（`aria-label` 以「的操作」结尾）并 `click()` 它。好处是菜单项、图标、快捷键、删除项的
  红色危险色全部由官方渲染，**官方改版也不会漂移**；代价是菜单位置跟随按钮而不是鼠标。
  官方改了 DOM 导致找不到按钮时，放行浏览器原生菜单兜底。
- 灯箱（点开的大图预览）内部不接管——只对对话区里**未展开**的图片出菜单。
- 「发送给 AI」会以当前输入框草稿为空板发送**选区内容本身**；想带上自己补的话，用「引用到输入框」。
- 右键目标须能取到选区、链接、图片、代码块、路径属性或所在段落文本；纯装饰元素上右键不出菜单。
- 相对路径要拼工作区根才能显示文件操作与「复制相对路径 / 复制本地文件链接」；
  取不到工作区根时，这些项不出现（绝不猜路径）。
- 粘贴依赖 Clipboard API 的读权限（需要用户手势，菜单项激活满足条件）；个别环境被拒时用 Ctrl+V。
- 「复制为代码块」按 `<pre>` 上 `language-xxx` / `lang-xxx` 类名或 `data-lang` / `data-language` 属性
  判断语言；都没标注时只给不带围栏的版本。

## 0.4.1：移除「复制此段」

按用户要求，**取消右键菜单里的「复制此段」**（段落菜单、文件芯片菜单两处），其余一项未动：

- 段落菜单现在是「引用此段到输入框 · 让 AI 解释此段 · 总结此段」；
- 文件芯片菜单保留 复制路径 / 打开文件位置 / 用默认应用打开 / 复制相对路径 / 复制本地文件链接 / 复制文件名；
- **代码块的「复制代码」照旧**；
- 删掉后，段落菜单在「没有活动会话」时会一项都不剩——这种右键现在**放行浏览器原生菜单**，不会出现「原生菜单被吞掉、自己的菜单也不弹」。

改完刷新页面（host 半帧未动，不必重启 DSH）。想还原：用 `lib/client.js.bak-去复制此段前-20261014-164445` 覆盖回去。

## 0.4.0 新增：状态行随机文案（自 dsh-status-rotator 提取）

运行中的那一行（原本写 `Deep diving…`）改为从词库里按阶段随机抽一句：`thinking`（0–15 秒）→ `running`（15–60 秒）→ `long`（≥60 秒），阶段切换立刻换句，其余每 10 秒轮换；洗牌袋保证一袋内不重复。词库为自带的 14 个包共约 1,210 句（`lib/status-phrases.json`），默认启用 10 个，关闭「社区投稿 / 求 star / 星标者路由 / 广告」。

只带走了「换文案 + 词库」。没带走：设置页、打字机、炫彩渐变、弹幕、标签页标题、鲸鱼尾巴、依赖实时引擎的占位符（`{tps}` `{model}` 等，对应约 11 句已剔除）。出现任何异常都会保持宿主原文。

覆盖与开关：创建 `~/.dsh/agent-menu/status-phrases.json`，重启后生效：

```json
{
  "enabled": true,
  "enabledPacks": ["deepseek", "coding", "daily"],
  "rotateMs": 8000,
  "longAfterMs": 90000,
  "packs": [
    { "id": "mine", "label": { "zh": "我的", "en": "Mine" },
      "phrases": { "zh": { "thinking": ["正在认真想…"], "running": ["正在埋头干…"], "long": ["还在跑，别急…"] } } }
  ]
}
```

- `"enabled": false` 关闭整个功能；
- `packs` 里 id 与内置相同则替换该包，否则新增（并默认启用）；
- 句子可写成字符串或 `{ "text": "…", "weight": 3 }`，支持占位符 `{elapsed}` `{phaseLabel}` `{phase}` `{time}` `{locale}`。

测试：`node tests/status-phrases.mjs`。
